Step through building the tree, then search it. Every step shows up in two places: the plane on the left and the tree on the right.

How the search works. To find the closest point we first find this point in the tree using a binary-style search. Then draw a circle from the query point to the closest point along that route. Any partition line that crosses over this circle is a region we will have to search for possible closer points.
