# Drafts

Working drafts of annotation and scaffolding documents for the ML course,
produced collaboratively with Claude. Review, edit, and promote to their
final locations (e.g., `notes/`) as appropriate.

## Current contents

- `ML_Course_Annotated_Outline.md` — annotated overview of the full year,
  organized by unit (12 units, Aug 21 – May 11). Covers the arc of the course,
  unit-by-unit summaries with linked resources, pedagogical themes, gap analysis,
  and a full resource inventory. Good starting point for a course syllabus or
  public-facing "about this course" page.

- `Unit4_Deep_Dive.md` — teacher-facing, deep annotation of the Sep 22 – Sep 26
  unit (Mushroom Exploration, self-selected categorical analysis, Bayes Error).
  Includes pedagogical observations and a list of small issues found in the
  notebooks.

- `Unit4_Student_Scaffolding.md` — student-facing, self-paced wrapper for Unit 4.
  Links into existing notebooks and notes, with inline `⚠️ GAP` callouts
  showing where supplementary lessons would help a self-learner.
